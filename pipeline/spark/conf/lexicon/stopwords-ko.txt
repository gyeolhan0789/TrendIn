# 한 줄에 하나, `#` 뒤는 주석. 비교키로 대조하므로 표기는 자유다.
#
# **여기 들어가는 것은 품사가 명사인데 무정보한 낱말뿐이다.** 조사·어미·용언·수식언·의존명사는
# 형태소 분석기가 아예 후보로 만들지 않으므로 (`extract/morphology.py` 의 품사표) 목록에 둘
# 이유가 없다. 2026-09-09 형태소 분석기 도입으로 **서술어 어간 절(`있` · `하` · `보` …)을
# 통째로 지웠다** — 어미를 뗀 어간이라는 것이 더 이상 생기지 않는다.
#
# 아래 남은 절 중 대명사·부사·수사·단위는 대부분 명사가 아닌 품사라 이미 닿지 않는다. 지우지
# 않은 이유는 어느 항목이 실제로 발동하는지를 재고 나서 지우려는 것이다 — 그 측정이
# `spark/scripts/evaluate-extract.py` 의 §7 불용어 발동 표다.
#
# **씨앗이다.** [04 §5] — 초기 목록은 표준 불용어에서 시작하고, DF 상한에 걸린 후보를 주기적으로
# 검토해 여기로 승격한다. 손으로 처음부터 쓰지 않는다.
