# fashion 형태소 분석기 사용자 사전 — 분석기가 **모르는 고유명사** (`extract/morphology.py`).
#
# 한 줄에 하나, `표기` 또는 `표기 품사`. 품사를 적지 않으면 `NNP`(고유명사)다. `#` 뒤는 주석.
# **원표기 그대로** 쓴다 — 비교키가 아니다. 분석기에게 "이런 낱말이 있다" 고 알려 주는 값이라
# 소문자로 접으면 뜻이 없다.
#
# ## 옛 protected-fashion.txt 와 무엇이 다른가
#
# 그 파일은 "조사 규칙이 이 어절을 자르지 못하게 막아라" 였다. 규칙이 없어졌으므로 그런 예외도
# 없어졌다. 여기는 반대로 **알려 주는** 것이고, 알려 주면 조사까지 옳게 떨어진다 —
# `발렌시아가와` 가 `발렌시아` + `가` + … 가 아니라 `발렌시아가` + `와` 로 갈린다.
#
# 그래서 옛 파일의 항목을 그대로 옮기지 않았다. 2026-09-09 에 38개 브랜드 × 조사 7종을 돌려
# **실제로 깨지는 14개만** 넣었다. 분석기가 이미 아는 이름(`샤넬` · `구찌` · `프라다` ·
# `에르메스` · `루이비통` · `버버리` · `펜디` · `랑방` · `겐조` · `몽클레르` · `셀린느` ·
# `베르사체` · `로에베` · `마르니` · `볼레로` · `요가` · `폴로` · `자크뮈스` · `르메르` ·
# `알라이아` · `토템` · `아페쎄`)은 넣어도 바뀌는 것이 없어 뺐다 — 사전이 짧을수록 다음
# 사람이 읽는다.
#
# **깨진 것은 15개였는데 14개만 넣었다.** 열다섯째가 옛 파일의 `올가을` 인데 브랜드가
# 아니고, 분석기가 `올`(MM) + `가을`(NNG) 로 갈라 후보가 `가을` 이 되므로 사전이 필요 없다.
# 규칙 시절 152회 `올가` 로 잘렸던 그 낱말이다 — 구조가 바뀌어 항목이 사라진 사례다.
#
# **씨앗이다.** 상위 100 후보를 눈으로 훑을 때([04 §9]) 조사가 붙은 채 남은 이름이나 두
# 토막으로 갈린 이름이 보이면 여기 올린다.

발렌시아가        # 발렌시아 + 가(조사) 로 갈렸다
보테가            # 보테 + 가
오프화이트        # 오프 + 화이트
아크네            # 아크 + 네
발망              # 발 + 망
지방시            # 지방 + 시
디올              # `디올와` · `디올가` 가 한 덩이가 됐다
자라              # 자라는 → 자라 + 는 은 맞지만 `자라도` 가 `자라 + 어도`(동사)로 갔다
아미              # `아미가` 가 한 덩이
젠틀몬스터        # `젠틀몬스터의` 가 한 덩이
코페르니          # `코페르니와` 가 한 덩이
미우미우          # 미우 + 미우
스톤아일랜드      # 스톤 + 아일랜드
메종마르지엘라    # 메종 + 마르지엘라. ⚠️ `-의` 가 붙은 형태는 아직 한 덩이로 남는다
