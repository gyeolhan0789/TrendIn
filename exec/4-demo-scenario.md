## ① 홈 — 첫인상과 트렌드 검색

**비로그인 상태로** 접속합니다.

| 조작 | 일어나는 일 |
| --- | --- |
| 화면 가운데에서 마우스를 좌우로 움직인다 | 파티클 물결에 포인터를 따라 파동이 생긴다 |
| 물결 위를 드래그한다 | 물결이 끌린 방향으로 회전한다 |
| 마우스 휠을 **한 번** 굴린다 | 다음 칸으로 스르르 내려가며 어둠이 걷히고 별이 흩어진다 |

**오늘의 트렌드** 칸에 도착합니다.

| 조작 | 확인 |
| --- | --- |
| 세 판을 본다 | **인기 · 신규 · 급상승** 각각 트렌드 3개가 순위·증감률과 함께 |

## ② 회원가입과 온보딩

로그인 화면 하단 **"회원가입"**.

| 조작 | 확인 |
| --- | --- |
| 이메일 입력 후 칸 오른쪽 **"확인"** 클릭 | 버튼이 **"✓ 확인"** 으로 바뀌고 *사용할 수 있는 이메일입니다* |
| 비밀번호를 한 글자씩 입력 | 아래 규칙 목록(영문·숫자·특수문자·8자)이 채워지는 대로 색이 바뀜 |
| 비밀번호 확인, 닉네임 입력 | |
| 약관 체크 **해제 상태**에서 가입 버튼을 본다 | 버튼이 잠겨 있음 |
| 체크 후 **"가입하기"** | 온보딩으로 이동 |

**온보딩** — 상단에 3단계(관심 분야 → 키워드 선택 → 알림 설정).

| 조작 | 확인 |
| --- | --- |
| **"게임"** 칩 클릭 | 선택되지 않고 *곧 오픈될 예정* 안내 |
| **"패션"** 칩 클릭 → **"다음"** | 2단계로 |
| 추천 칩 2~3개 클릭 | 아래 "담긴 키워드"에 쌓임 |
| **"시작하기"** | 홈으로 |

## ③ 트렌드 탐색

헤더 **"트렌드 탐색"**.

| 조작 | 확인 |
| --- | --- |
| 상단 리드 문구를 본다 | *"09.20 ~ 09.26 집계 · 직전 구간과 비교"* — 집계 구간 표시 |
| 기간을 `24시간` → `7일` → `30일` 로 바꾼다 | 세 판의 순위가 구간마다 다르게 바뀜 |
| 캐러셀 화살표로 판을 넘긴다 | 인기 → 신규 → 급상승 |
| **급상승 판 1위의 증감률**을 본다 | 언급량은 작아도 증가율이 큼 — **이 서비스의 핵심** |
| 아무 줄의 북마크 아이콘 클릭 | 색이 바뀌며 저장 |

아래로 스크롤합니다.

| 조작 | 확인 |
| --- | --- |
| **"함께 떠오르는 키워드"** 패널 | 내 관심 키워드와 같이 언급되는 말이 칩으로 |
| 칩 하나 클릭 | 관심 키워드에 담김. 다시 누르면 해제 |

## ④ 트렌드 상세 (가장 중요)

순위판에서 **인기 1위**를 클릭합니다. 오른쪽에서 패널이 밀려 나옵니다.

| 조작 | 확인 |
| --- | --- |
| 뒤 화면을 본다 | **탐색 화면이 그대로 남아 있음** |
| 상단 핵심 지표 | 구간 언급량, 직전 구간 대비 증감률, 집계 구간 |
| 차트 막대에 마우스를 올린다 | 말풍선으로 값과 시점 |
| **"지금 뜨는 이유"** 카드 | **주요 흐름**과 **주목받는 이유** — LLM 이 원본 기사를 읽고 쓴 것 |
| **"키워드가 언급된 원본 소스"** | 기사 제목·매체·날짜 — 해설의 근거 |
| 기사 하나 클릭 | 새 창으로 원문 |
| 소스 목록 헤더의 **→** | 다음 쪽 기사 |
| **"연관 키워드"** 칩 클릭 | 관심 키워드에 담김 |
| **"타임라인"** | 트렌드가 커진 경로가 날짜순으로 |
| 상단 기간 버튼을 `7일` 로 | 지표·차트·해설이 **모두** 다시 그려짐 |
| 좌상단 **←** | 탐색 화면의 **원래 자리로** 복귀 |

> 💡 **"지금 뜨는 이유" → "원본 소스" → 기사 클릭** 순서가 시연의 절정입니다. 숫자에서 해설, 근거 원문까지 한 화면에서 이어지는 흐름을 천천히 보여 주세요.

## ⑤ 관심 키워드

헤더 **"관심 키워드"**.

| 조작 | 확인 |
| --- | --- |
| 상단 통계 카드 3개 | 관심 키워드 수 · 관심 분야 수 · 안 읽은 알림 수 |
| 상단 입력칸에 키워드 입력 | 아래로 검색 결과가 펼쳐짐 |
| 결과 항목의 **＋** 클릭 | 목록과 통계가 함께 갱신 |
| 정렬을 `가나다순` 으로 | 순서 변경 |
| 아래 **"추천 키워드"** 패널 | 연관도 상위 **40개**가 8개씩 쪽 번호로 |
| 쪽 번호 2, 3 클릭 | 다음 묶음 |

## ⑥ 국가별 트렌드

헤더 **"국가별 트렌드"**.

| 조작 | 확인 |
| --- | --- |
| 지도 전체를 본다 | 언급량에 비례해 나라가 진하게 칠해져 있음 |
| 왼쪽 목록에서 나라 하나 클릭 | 오른쪽 요약이 바뀜. **지도는 당겨지지 않음** |
| 지도 위 **"선택 국가 확대"** | 그제야 지도가 그 나라로 |
| 상단 탭 **"트렌드별 추이"** | 축이 바뀌고 지도가 세계 전체로 |
| 기간 `30일` + 목록에서 **`NEW` 표가 붙은 트렌드** 선택 | 지도 위에 **"흐름보기"** 버튼이 나타남 |
| **"흐름보기"** | 나라를 잇는 확산 경로가 그려짐 |
| **"경로 따라가기"** | 비행기가 구간을 차례로 건너감 |
| 지도를 드래그 | 지구본이 회전 |
| 좌우 가장자리 손잡이 클릭 | 패널이 접히고 지도가 넓어짐 |

> ⚠️ **흐름보기는 `30일` 구간의 신규 트렌드에서만 열립니다.** 시연 전에 조건을 만족하는 트렌드를 미리 찾아 두세요.

## ⑨ 마이페이지

헤더 계정 아이콘 → **"마이페이지"**.

| 조작 | 확인 |
| --- | --- |
| 상단 | 프로필과 통계 카드 4개 |
| **"알림 설정"** 카드의 토글 하나를 끈다 | 즉시 저장 |
| **"전체 관리 →"** | 네 가지 알림 전체 |
| **"프로필 편집"** | 닉네임·이메일·관심 분야 |

| 맨 아래 **"위험 영역"** → **"계정 삭제"** | 대화상자: *정말 계정을 삭제하시겠습니까?* |
| **"취소"** | 닫힘 |

> ⚠️ **반드시 "취소"를 누르세요.** "영구 삭제"는 되돌릴 수 없습니다.
