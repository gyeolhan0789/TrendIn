# 백엔드 작업 요약

TrendIn(트렌드 탐지·분석 서비스) 백엔드에서 맡은 작업 중 기술적 판단이 담긴 세 가지입니다.
각 문서는 **문제 상황 · 접근 방법 · 대안 · 기술 선택 이유 · 해결 과정 · 결과** 순서로 정리했습니다.

| # | 주제 | 한 줄 | 핵심 수치 |
| --- | --- | --- | --- |
| 1 | [알림 조회 인덱스](01-notification-index.md) | 인덱스 둘로 응답 시간을 줄였다 | p95 **900ms → 7ms** (123×) |
| 2 | [부하테스트 환경 설계](02-load-test.md) | 믿을 수 있는 측정 환경을 만들었다 | 회원 1만 · 450만 행 |
| 3 | [리프레시 토큰 동시성](03-refresh-token.md) | Lua 로 세션 레이스를 막았다 | 왕복 1회 · 의존성 0 |

세 작업은 이어져 있습니다. **②로 병목을 찾아 ①을 고쳤고**, ③은 그 과정에서 인증 경로를 들여다보다 발견한 문제입니다.

## 사용 기술

`Java 25` · `Spring Boot 4.1.1` · `Spring Data JPA` · `PostgreSQL 17` · `Redis 8` · `Flyway` · `k6`

## 더 자세한 내용

측정 원본과 인덱스 설계 근거는 [기술 리포트](../report.md)에 있습니다.
