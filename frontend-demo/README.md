# frontend-demo · ahead.

관심 분야 하나에 집중하는 화이트 배경과 절제된 포인트 색상을 사용하는 인터랙티브 트렌드 대시보드입니다.

## 실행

현재 공개 사이트의 프론트엔드 데모 소스입니다. React / TypeScript 기반이며 Vinext로 실행합니다. 백엔드 연동 없이 예시 데이터로 동작합니다.

Node.js 22.13 이상을 사용합니다. 저장소 루트에서 다음 명령을 실행하세요.

```sh
cd frontend-demo
npm ci
npm run dev
```

```sh
npm run build
npm run lint
npx tsc --noEmit
```

## 페이지

- `/`: 선택한 **v1 디자인**을 사용하는 메인 대시보드. 상단 메뉴에서 별도 탐색 페이지로 이동합니다.
- `/world`: 1일·7일·30일 전환을 제공합니다. 1일은 시간대별, 7일은 날짜별 국가 관심 지수·순위·변화 그래프를 기존 디자인으로 보여줍니다. 이 두 화면에는 비행기·확산 경로·재생 컨트롤이 없습니다. 30일은 확산 타임라인으로, 기본 비행 속도는 하루당 550ms(기존 850ms 대비 약 1.5배)입니다. 기간 내 최초 관측 국가, 국가별 등장 순서, 가설 경로와 방향을 지도에서 확인합니다. 재생/일시정지, 1×·2× 속도, 날짜 슬라이더, 하루 이동 및 다음 관측 건너뛰기를 지원합니다. 선택한 날짜까지의 관측 국가·기록·누적 차트와 현재 이동 중인 가설 경로를 표시합니다. 국가를 누르면 최초 관측일, 일별/누적 언급 예시와 경로 근거 상태를 확인합니다.
- `/search`: 트렌드명·설명·태그·연관 키워드·일부 한글 별칭 검색. 내 관심 분야/개별 분야, 유형, 저장 여부 필터와 관련도·언급량·증가율 정렬. 결과 더보기, 최근 검색 삭제, 빈 상태, 상세·저장 지원. `?q=&category=`로 검색어와 분야를 전달합니다. 전체 분야 탭은 제공하지 않으며 기본/초기화 범위는 내 관심 분야입니다.
- 공통 메뉴는 대시보드 ↔ 세계 추이 ↔ 트렌드 검색을 연결합니다. 상세 패널에서 현재 키워드의 다른 페이지로 이동할 수 있고, 검색 결과의 세계 추이 링크는 `/world?trend=`로 같은 키워드를 전달합니다. 신규·급상승 항목과 온보딩 밖 분야도 해당 항목을 유지하며 열립니다.
- 세 페이지에서 관심 분야와 저장 목록을 공유합니다. 세계 추이와 검색 기능은 메인 콘텐츠에 넣지 않았습니다.

## 초안 비교

- **초안.v1 — Grid**: `/drafts/v1`. 사용자가 승인한 화이트 카드 그리드 스타일을 보존했습니다.
- **초안.v2 — Editorial**: `/drafts/v2`. 같은 색상을 유지하고 큰 제목, 순위 인덱스, 구분선 중심으로 구성한 대안입니다.
- **초안.v3 — Stage**: `/drafts/v3`. 가로 순위 라인에서 트렌드를 선택하면 중앙에 해당 키워드가 펼쳐집니다. 신규·급상승·인사이트는 접고 펼쳐서 탐색합니다.
- 상단 비교 바에서 세 시안을 전환할 수 있습니다. 관심 분야와 저장 상태는 공유됩니다.
- v1 원본은 `design-drafts/초안.v1.zip`에 따로 보관합니다. 원본 작업 저장소의 `초안.v1` 태그에서 추출한 파일이며, 해당 Git 이력과 태그는 이 저장소로 가져오지 않았습니다.

## 화면 구성

- 현재 관심 분야 하나만 표시하고, 옆의 전환 버튼에서 온보딩 관심 분야를 선택합니다. 관심 분야 편집에서 9개 분야 중 2~3개를 선택할 수 있습니다.
- 현재 분야의 Top 5를 1위 강조 카드와 2~5위의 2×2 카드 그리드로 표시합니다. 순위 변동, 언급량과 증가율을 각 카드에 담았습니다. 24시간·7일·30일 기간별 예시가 있습니다.
- 신규·급상승 트렌드 각 2개와 더보기.
- 1위 스포트라이트, 트렌드 인사이트, 연관 키워드 추가.
- 트렌드 상세 패널, 저장 목록, 빈 상태, 키보드 포커스 관리.
- 모바일 레이아웃 및 모션 축소 설정 지원.

## 데이터와 범위

모든 데이터와 분석 문구는 `app/trends.ts`의 가상 예시입니다. 차트 역시 가상 데이터이며 실제 측정 지표가 아닙니다. 실제 수집, 순위 산정, LLM 분석, 원문 기사, 회원 인증, 알림 기능은 연결되지 않았습니다. 기간 변경도 서버 조회가 아닌 예시 데이터 전환입니다.

선택한 분야·관심 키워드·저장한 트렌드는 브라우저의 localStorage에 보관합니다. 이는 기기 로컬 프로토타입 설정이며 계정 간/기기 간 동기화는 없습니다. 관심 키워드 추가가 추천 순위에 영향을 주지는 않습니다.

1일·7일 데이터는 `app/country-interest.ts`의 기존 국가별 관심 지수 예시를 복원한 것입니다. 1일은 08.30의 00–24시, 7일은 08.24–08.30을 표시하며, 30일 시나리오의 언급량을 집계한 값은 아닙니다. 기간 변경 시 현재 키워드를 유지하고, 1일↔7일에서는 선택 국가도 유지합니다. 30일로 돌아오면 확산 애니메이션이 새로 시작됩니다.

30일 세계 추이 데이터는 `app/world-data.ts`의 작성된 가상 시나리오입니다. 2026.08.01–08.30의 30개 일별 기록을 표시합니다. 6개국만 추적하며 미표시 국가는 데이터가 없습니다. `firstDay`는 기간·수집 범위 내 최초 관측일이고 실제 발생일이 아닙니다. `parent`는 시연용 전파 가설로 관측 순서에서 자동 추론하지 않습니다. 원문 인용·재게시 관계 등의 근거를 연결하기 전까지 경로는 미검증으로 표시합니다. 페이지 진입과 키워드 전환 시 자동 재생합니다. 비행기 아이콘이 가설 경로를 따라 연속 이동하고, 도착 날짜에 관측 기록이 추가됩니다. 30일이 끝나면 잠시 머문 뒤 반복합니다. 날짜 이동이나 국가 선택 시 멈추며 이어 재생할 수 있습니다. 날짜를 되감으면 미래 관측 기록을 숨깁니다. 탭이 숨겨지거나 상세 패널이 열리면 일시 정지하고 돌아오면 이어집니다. 기기의 모션 줄이기 설정에서는 자동 재생을 끄고 날짜 수동 탐색을 제공합니다. 비행기는 확산을 설명하는 아이콘이며 실제 항공 이동을 나타내지 않습니다. 지도 지형은 Natural Earth의 공개 지리 데이터로 구성한 벡터입니다 (`THIRD_PARTY_NOTICES.md` 참조). 이미지 및 AI 생성 이미지를 사용하지 않습니다.

검색은 서버 검색 서비스 없이 `app/search-data.ts`에서 예시 데이터 99개를 대상으로 수행합니다. 최근 검색 8개는 브라우저 내 기기 로컬 설정으로 저장하고 개별/전체 삭제를 지원합니다. 온보딩 전용 페이지와 주간 브리핑은 아직 구현하지 않았습니다.

## 구현

Vinext / React / TypeScript / CSS. `app/_components/dashboard-v1.tsx`와 `dashboard-v2.tsx`는 각 시안 화면을, `app/globals.css`와 `app/panels.css`는 보존한 공통 스타일을, `app/editorial.css`는 v2 전용 스타일을 담당합니다. `app/preferences.ts`는 브라우저 내 설정을 저장합니다.

## 검증

`node scripts/verify-exploration.mjs`는 한글/영문 검색, 복합 필터, 정렬, 저장 필터, 빈 검색 결과 및 1,350개 키워드·날짜 조합의 관측 시간 순서, 부모 경로의 선행성, 미래 기록 숨김, 되감기 및 경계값을 확인합니다.

## 페이지 이동

공개 배포에서 Vinext의 `next/link`가 기본 클릭을 막은 뒤 클라이언트 라우터 함수를 로드하지 못하는 오류가 확인되어, 모든 페이지 링크는 `app/_components/page-link.tsx`의 네이티브 앵커로 이동합니다. 검색 매개변수, 키보드 Enter, 새 탭, 브라우저 뒤로가기와 앞으로가기는 브라우저가 처리합니다. 관심 분야와 저장 목록은 기존 localStorage 설정으로 유지됩니다.
