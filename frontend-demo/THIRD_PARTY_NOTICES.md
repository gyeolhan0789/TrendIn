# Geographic data

`app/world-land.json` contains simplified display paths projected from Natural Earth's 1:110m land data. Antarctica is omitted from this map viewport. This is geographic geometry, not trend measurement data.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Publisher: Natural Earth
- Terms: https://www.naturalearthdata.com/about/terms-of-use/
- License: public domain
- Downloaded: 2026-08-31

The map does not indicate national boundaries or territorial claims. Trend country markers and all numerical values are separately defined fictional UI fixtures.
